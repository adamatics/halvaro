# halvaro-delivery

A task needs one of the computations below. Look here first: if the function you need is not in the table, say so and ask for it to be added; do not write a private copy of the rule.

## Rules

- Import from the package: `from halvaro.delivery import <name>`. Each function has a reference page in `references/<name>.md` (signature, docstring, source columns, facts).
- The library never reads data, files, credentials or the environment. Your app loads the tables and passes them in as DataFrames with the source column names.
- Rule values are facts read with `halvaro.core.fact(id)`. Never type one. A fact with status proposed or VERIFY is provisional: say so when a number depends on it.
- Generated by `tools/build_skill.py` from the docstrings and the registry. Do not edit by hand.
